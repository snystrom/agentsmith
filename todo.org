* TODO branch shown on worktree section is stale
The =:branch= slot on =agentsmith-worktree= is set once at creation
(=agentsmith-buffer.el= ~line 953, ~:branch ws-name~) and persisted in
=.agentsmith.el=. Render at =agentsmith-buffer.el= ~line 335 reads the
cached value, so:
- the displayed branch is always the workspace name, not the actual git
  branch in the worktree;
- switching branches in the worktree (e.g. via magit) never updates the
  agentsmith UI.
A correct live-query already exists: =agentsmith-worktree-branch-info=
in =agentsmith-worktree.el= (git: ~rev-parse --abbrev-ref HEAD~; jj:
bookmarks template). Fix is to call it at render time and treat the
cached =:branch= slot as a fallback only.
